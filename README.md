# Qoute Module

Модуль расчёта стоимости лазерной резки металла.

Проект реализуется на Python и предназначен для разработки основной расчётной логики: обработки входных данных, подготовки внутренних структур и последующего вычисления стоимости заказа. В дальнейшем модуль может использоваться как самостоятельный компонент системы или интегрироваться с другими сервисами.

## Требования

Для работы с проектом необходимы:

- Python 3.10 или выше
- pip
- venv

## Подготовка окружения

Создай виртуальное окружение:

```bash
python3 -m venv .venv
```

Активируй виртуальное окружение:

```bash
source .venv/bin/activate
```

Установи проект в editable-режиме:

```bash
python -m pip install -e .
```

## Запуск проекта

После активации виртуального окружения проект можно запустить командой:

```bash
python -m quote_core.main
```

## Сборка проекта


```bash
python -m build
```

После успешной сборки артефакты появятся в директории `dist/`.
